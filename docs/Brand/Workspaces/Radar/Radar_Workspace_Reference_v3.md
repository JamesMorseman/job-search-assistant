# Purpose

The Radar Workspace serves as the discovery layer of ATLAS.

Narrative:

ATLAS scans.

Atlas interprets.

Ask Atlas communicates.

The Radar workspace represents the moment opportunities are detected and surfaced for investigation.

---

# Product Role

Radar is not:

- a job board
- an application tracker
- an analytics dashboard
- a Kanban board

Radar is:

- opportunity discovery
- signal detection
- opportunity monitoring
- prioritization

The user should feel they are monitoring a live intelligence system rather than browsing listings.

---

# Accepted Visual Direction

## Core Concept

Opportunity cards function as active radar returns.

Each opportunity appears as a detected signal rather than a database record.

Visual emphasis is placed on:

- discovery
- detection
- confidence
- signal strength

---

## Signal Tiers

### Strong Signal

Characteristics:

- brightest sweep
- strongest glow
- densest returns
- highest perceived confidence

Color family:

- cyan / blue

---

### Moderate Signal

Characteristics:

- reduced intensity
- balanced return density
- moderate activity

Color family:

- blue-violet

---

### Emerging Signal

Characteristics:

- faintest sweep
- sparse returns
- greatest negative space

Color family:

- violet

---

# Radar Variation Standard

No two visible Opportunity Signal Cards should share:

- identical sweep angle
- identical return placement
- identical return density
- identical radar composition

The purpose is to create subconscious recognition of opportunities before users read titles.

Signal cards should feel detected, not duplicated.

---

# Workspace Objectives

The Radar workspace should communicate:

1. New opportunities detected
2. Relative signal confidence
3. Opportunity context
4. Opportunity investigation workflow

without becoming:

- ATS software
- CRM software
- spreadsheet software

---

# Accepted Layout Structure

Top Section:

- filters
- search
- signal summary metrics

Center Section:

- opportunity signal grid

Right Context Panel:

- selected opportunity details
- related intelligence
- recommendation context
- Ask Atlas entry point

---

# Design Decisions Accepted

Accepted:

- variable radar sweeps
- variable signal densities
- signal-strength visual differentiation
- persistent context panel
- intelligence-oriented terminology
- dark ATLAS visual system

Rejected:

- identical radar graphics
- job-board presentation
- generic card grids
- ATS-style tables
- excessive analytics within Radar

## Purpose

This directory is reserved for Visual Object Specs - one file per object - written
using `../templates/Visual_Object_Spec_Template.md`. New specs must start as Draft
unless Main Ash explicitly accepts them. See `../VISUAL_GOVERNANCE_V1.md` migration
plan: object specs are a near-term step, not part of this template-foundation package.

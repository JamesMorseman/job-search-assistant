# ATLAS Focus Object v1 Visual Reference

**Authority:**

* Command Center Object Study
* Command Center Surface Specification
* Desktop v1 Visual Implementation Readiness Study

**Status:** Object Visual Definition

---

# Design Intent

The Atlas Focus is the defining object of Command Center.

Radar owns:

```text
Opportunity Signal
```

Pipeline owns:

```text
Opportunity Progression
```

Command Center owns:

```text
Atlas Focus
```

A Focus is not:

```text
Notification
Task
Alert
Reminder
```

Those communicate:

```text
Something happened.
```

A Focus communicates:

```text
This deserves attention.
```

That distinction defines the object.

---

# Core Definition

An Atlas Focus is:

```text
A prioritized awareness object
that elevates something Atlas
believes deserves near-term attention.
```

Not because it is urgent.

Not because it is overdue.

Because it matters.

---

# Visual Identity

The Focus should feel:

```text
Deliberate
Relevant
Important
```

Not:

```text
Urgent
Dangerous
Critical
```

The object must pull attention without creating anxiety.

---

# Primary Visual Innovation

Unlike a recommendation:

```text
Atlas thinks this is worth considering.
```

A Focus says:

```text
You should be aware of this now.
```

Therefore the visual emphasis should come from:

```text
Attention Horizon
```

rather than:

```text
Confidence
```

or

```text
Signal Strength
```

---

# Object Anatomy

## Region 1

### Focus Identity

Highest visual hierarchy.

Contains:

```text
Focus Type

Focus Title
```

---

## Region 2

### Reason

Immediately beneath title.

Purpose:

```text
Why am I seeing this?
```

---

Rule:

One concise explanation.

Never a paragraph.

Never analytics.

Never system detail.

---

## Region 3

### Related Object

Provides context.

---

## Region 4

### Recommended Action

The operational center of the object.

---

Purpose:

```text
What should I do?
```

---

## Region 5

### Attention Horizon

The defining Focus attribute.

---

Purpose:

```text
When does this matter?
```

---

## Region 6

### Resolution State

Lowest hierarchy.

---

States

```text
Active

Deferred

Resolved
```

Desktop v1 only.

---

```

```

---

```text

```

---

The Focus sits between:

```text
Recommendation
```

and

```text
Action
```

inside the Command Center hierarchy.

---

# Emotional Outcome

A user encountering a Focus should immediately feel:

```text
I should pay attention to this.
```

Not:

```text
Something broke.
```

Not:

```text
I received a notification.
```

Not:

```text
I have another task.
```

The ideal response is:

```text
This appears important.

I understand why.

I know what to do next.
```

That outcome makes Atlas Focus the canonical Command Center object and completes the Desktop v1 core object family.

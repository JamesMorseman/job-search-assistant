# <a name="purpose"></a>Purpose
This document defines the complete visual asset inventory required to implement ATLAS.

The objective is to:

- prevent missing assets
- support implementation planning
- support commercialization readiness
- support future desktop deployment

This inventory identifies:

- what must exist
- why it exists
- where it is used
- when it should be produced

This document does not define visual design.

It defines asset requirements.

# <a name="success-criteria"></a>Success Criteria
The asset library is complete when a future implementation team can build:

- Command Center
- Radar
- Pipeline
- Intelligence
- Ask Atlas
- Desktop Experience
- Marketing Site
- Documentation System

without needing to invent new visual assets, states, icons, or motion primitives outside the approved ATLAS design system.

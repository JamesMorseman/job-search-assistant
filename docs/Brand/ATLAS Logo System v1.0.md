-----
# <a name="purpose"></a>1. Purpose
This document defines the official ATLAS logo system.

The purpose is to transition from brand exploration into production-ready asset creation.

This specification should provide sufficient guidance for a designer to create:

- SVG assets
- PNG exports
- Desktop application icons
- Taskbar icons
- Documentation assets
- Marketing assets

without reopening logo exploration.

-----
# <a name="logo-philosophy"></a>2. Logo Philosophy
ATLAS is a Career Intelligence System.

The logo represents:

- awareness
- detection
- monitoring
- discovery
- situational awareness

The logo does not represent:

- conversation
- assistance
- chat
- AI

Those belong to Atlas and Ask Atlas.

-----
# <a name="core-narrative"></a>Core Narrative
ATLAS scans.

Atlas interprets.

Ask Atlas communicates.

The ATLAS logo represents the first stage only:

Scanning.

# <a name="official-logo-definition"></a>Official Logo Definition
The official ATLAS logo is a radar-derived awareness symbol consisting of a circular scan field, a single sweep segment, and a detected signal point paired with the ATLAS wordmark in a horizontal lockup.

The logo communicates continuous situational awareness and serves as the visual representation of the ATLAS platform.

Its purpose is to symbolize the platform’s ability to scan the professional landscape, detect meaningful opportunities, and maintain awareness of what matters.

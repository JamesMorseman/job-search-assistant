# Donut Review — ATLAS Desktop v1 Freeze Criteria

**Role:** Donut (Product Strategy)
**Authority:** Desktop Personal Edition v1 Product Definition, MVP Cutline, Surface Inventory, Launch Readiness Assessment
**Status:** Freeze Criteria Definition

---

# Executive Purpose

This document exists for one reason:

> To prevent Desktop v1 from becoming Desktop v2.

ATLAS now possesses sufficient product definition to enter implementation.

The remaining strategic danger is uncontrolled expansion.

This document defines the exact point where Desktop Personal Edition v1 should be considered complete.

---

# Freeze Principle

Desktop v1 is complete when:

```text
A user can discover,
evaluate,
track,
prioritize,
and investigate opportunities
without requiring external tracking systems.
```

Everything else is optional.

This is extremely important.

---

## MUST EXIST

* be visible
* be understandable
* be actionable

```text

```

## Atlas Must Be Able To

---

### Identify Attention Requirement

---

### Identify Priority Shift

Example:

Opportunity becoming more important.

---

---

## NICE TO HAVE

---

## OUT OF SCOPE

Career strategy engine.

Forecasting engine.

Life planning engine.

Recommendations do not need to be predictive.

# Final Launch Gate

Desktop Personal Edition v1 is officially complete when a user can truthfully say:

> I can discover opportunities, understand opportunities, track opportunities, prioritize opportunities, and investigate opportunities entirely inside ATLAS.

And:

> ATLAS is the first place I check when I want to understand the current state of my professional opportunity landscape.

If both statements are true, Desktop v1 has achieved its purpose as a Professional Mission Control system and should ship, regardless of how many future Career Intelligence features remain unbuilt.

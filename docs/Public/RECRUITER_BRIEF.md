# Recruiter Brief

ATLAS is a local-first Career Intelligence / Career Mission Control system. It
organizes a career search into a private operating system: finding
opportunities, evaluating fit, generating application materials after review,
tracking progress, and surfacing what needs attention next.

In plain English, ATLAS helps one person manage a complex job search with the
same discipline used in engineering systems: clear inputs, traceable decisions,
repeatable workflows, and visible status.

## What It Does

ATLAS gathers job opportunities from multiple sources, removes duplicates,
scores each opportunity, grades fit with an LLM-assisted workflow, and presents
the results for human review. When an opportunity is selected, it can generate
tailored resume and cover-letter drafts, upload document snapshots, mirror
review data to Sheets, and track application follow-ups.

The system also includes a local FastAPI dashboard and an ATLAS Desktop
interface with workspaces for command overview, opportunity radar, pipeline
status, opportunity detail, recommendations, Ask Atlas investigation, and Focus
items.

## Engineering Skills Demonstrated

- Python application architecture and CLI design.
- SQLite data modeling and local-first persistence.
- FastAPI service and route design.
- React 18, TypeScript, and Vite frontend implementation.
- Service-boundary discipline for reads, writes, and workflow ownership.
- LLM provider abstraction without tying product behavior to one client path.
- Document generation, external integration, and audit-friendly workflow design.
- Test-driven package implementation with regression checks and scope controls.

## Why It Matters For A Civil Engineering Candidate

The project shows practical engineering judgment beyond coursework: building a
working system, decomposing it into maintainable components, validating changes
with tests, and designing for real operational constraints. It connects
software automation to a civil engineering career search by evaluating
discipline fit, location fit, benefits, trajectory, employer context, and
follow-up timing.

For portfolio readers, the most important signal is not that the system
automates paperwork. It demonstrates the ability to structure an ambiguous
real-world process, build dependable tools around it, and keep the human
decision point explicit.

## Short Summary

ATLAS is a private Career Intelligence / Career Mission Control system that
combines Python, SQLite, FastAPI, React/Vite, and LLM-assisted workflows to
support opportunity discovery, evaluation, application document generation,
tracking, analytics, and focused decision-making.
